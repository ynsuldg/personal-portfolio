Two-Factor Authentication

Project Individual Work Course 4: Enterprise Java Development

A standalone project where I built a secure login flow with Spring Boot and Spring Security. Users can register, choose whether to enable two-factor authentication, and then sign in using a password and a time-based code from Microsoft Authenticator or Google Authenticator.

The project generates a secret key that is stored in PostgreSQL and embedded in a QR code that can be scanned by an authenticator app. Protected pages require both a successful login and a verified MFA code.

This is a school project created for educational and demonstration purposes.

The application has no CSS styling, as the focus was on the security functionality. To test two-factor authentication, select it when creating an account, scan the QR code with an authenticator app and confirm the code. The account is only created once the code has been confirmed.

Flows for deleting accounts are now available, along with demo flows for resetting the password and two-factor authentication.
